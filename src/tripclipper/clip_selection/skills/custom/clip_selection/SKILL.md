# 最小选片方法

1. 先理解 Brief 的目标时长、节奏、开头、人物、环境和景别要求。
2. 用 `asset_list` 浏览全部分页，不能只看高星素材；星级只是参考。
3. 根据 Brief 与素材实际内容建立少量有用途的分类，禁止一片一类。
4. 对可能承担关键用途的素材按需调用 `asset_get`，比较已有 `clip_suggestions`、画面摘要、技术缺陷和重复性。
5. 添加第一个主选前，先规划完整候选集合并算好时间并集；总时长必须位于目标的 100%～150%，不要逐条试加或超额囤积。
6. 添加主选时优先覆盖不同内容与景别，理由同时写出可见证据和相对选择依据；一个候选可以覆盖多个分类。
7. 开头候选应有明确的 `recommended_use`；明显遮挡、失焦、抖动或长时间无变化的素材不作为主选。
8. 一旦全部必要分类已覆盖且主选总时长达标，立即请求完成，不要继续添加可有可无的候选。
