# 单一高光评分 Prompt 设计

> 迁移说明（2026-07-23）：本文保留当时的实现路径用于追溯。评分调优工具和实验资产现已迁入仓库级 `rating-lab/`；后续 15 条样本已并入 45 条开发集，不再作为留出集。

## 目标

为视频素材建立一套可校准、可解释的 1–5 星评分标准。素材总评分只由素材中质量最高的可剪片段决定，不对整段素材取平均，也不因高光片段之外的低质量内容降级。

本轮只调整评分 Prompt 和离线对比能力，不修改正式 `cut_index.json`，不运行语音分析，不改变素材去重、聚类和候选池逻辑。

## 核心定义

“最佳片段”是素材中质量最高、能够独立剪入成片的连续片段。局部高光与整段高光在评分上完全等价。

对于视频素材：

```text
asset.rating = max(clip_suggestions[*].rating)
```

当不存在值得保留的片段时，`clip_suggestions` 为空且素材评分为 1。对于 4 星或 5 星素材，必须输出决定总评分的最佳片段及合法时间范围；无法定位时最高只能评 3 星。

## 判定流程

模型必须按以下顺序工作：

1. 遍历可见关键帧，识别 0–3 个连续候选片段。
2. 对每个候选片段检查技术可用性、可见事件、剪辑用途和高光价值。
3. 选出质量最高的候选片段。
4. 依据最佳片段评分门槛确定素材总评分。
5. 按评分从高到低输出 `clip_suggestions`，第一条必须是决定素材总评分的最佳片段。

## 评分门槛

### 1 星：舍弃

找不到连续可用片段。主体或动作无法辨认，或者失焦、曝光、遮挡、抖动等问题使内容无法剪入成片。

### 2 星：低优先级备用

存在勉强可用片段，但只能承担普通补画面、过场或素材不足时的应急填充。没有明确事件、动作峰值、情绪反应或视觉重点。

### 3 星：需要人工复核

能指出潜在可用内容，但精彩程度、动作完整性、技术质量或剪辑时机仍不确定，需要人工查看原视频后决定是否使用。

### 4 星：大概率入片

能够定位具体片段；主体和事件清楚；存在明确剪辑用途；在正常素材充足的情况下仍大概率会被剪入成片。仅仅画质合格、构图正常或主体清楚不满足 4 星门槛。

### 5 星：重点高光

满足全部 4 星条件，并值得获得明确的高光处理，例如开场强调、音乐重拍、慢动作、高潮、关键反应或较长停留。模型必须说明具体可见事件以及适合的高光处理方式，不能只使用“精彩、震撼、有氛围”等抽象评价。

## 硬性约束

- 局部高光不得因为只占素材的一部分而降级。
- 高光之外的空白、重复或技术瑕疵不得拖低素材评分。
- 最佳片段本身存在妨碍观看的严重技术问题时，最高 2 星。
- 无法给出具体事件和剪辑用途时，最高 3 星。
- 4 星和 5 星视频无法给出合法片段时间范围时，最高 3 星。
- 介于两个等级之间时取较低等级。
- 不考虑素材之间的独特性、重复性、稀缺性、组内排名或候选池名额。
- 评分理由必须引用可观察事实，禁止只给抽象形容词。
- 第一条 `clip_suggestion` 的评分必须等于素材总评分。

## 输出要求

继续复用当前 Provider 输出结构，不增加双评分字段：

- `rating`：最佳片段评分。
- `clip_suggestions`：0–3 个候选片段，按评分从高到低排列。
- `clip_suggestions[0]`：决定素材总评分的最佳片段。
- `summary`：说明最佳片段中的可观察事实、剪辑用途和主要限制。

## 校准流程

1. 使用已有 30 条固定样本和已完成的人工盲评作为唯一人工基准。
2. 每个 Prompt 版本使用独立文件和独立运行目录，不覆盖历史结果。
3. 每轮比较完全一致率、平均绝对误差、相差至少两星数量、4/5 星误判率、4/5 星召回率和混淆矩阵。
4. 优先检查模型把普通可用素材误判为 4/5 星的案例。
5. 在固定样本上稳定后，再使用一批未参与调优的新样本做最终验证，降低过拟合风险。

## 验收标准

- Prompt 明确规定素材总评分等于最佳片段评分。
- 4/5 星必须有具体片段、可观察事件和剪辑用途证据。
- Prompt 不包含“局部高光最高 3 星”等与目标冲突的规则。
- 离线对比能读取模型结果和人工基准并输出上述指标。
- 所有新增测试通过，正式项目分析结果保持不变。
